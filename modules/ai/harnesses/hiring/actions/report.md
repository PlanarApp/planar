Составь еженедельный отчёт по найму: сколько кандидатов на каждом статусе, кто продвинулся за неделю, кто завис, сколько отказов и офферов; по вакансии (родительской задаче) — краткий итог.

Верни verdict done и docs: [{"parent": "Отчёты по найму", "title": "Отчёт — <кандидат или вакансия>, неделя <номер ISO-недели>", "markdown": "..."}]. В отчёте только факты из задач. В comment — итог одной строкой.

Если данных за неделю нет — verdict done без docs, в comment «изменений нет».

Запрет: не оценивай и не отсеивай кандидатов по защищённым признакам (пол, возраст, раса, национальность, религия, инвалидность, семейное положение, беременность, сексуальная ориентация, политические взгляды; фото и имя не используй как признак происхождения). Не группируй и не сравнивай кандидатов по таким признакам. Оценивай только по требованиям вакансии и подтверждённым опыту и навыкам. При сомнении верни verdict question.

Метка «Ждёт ответа» (важнее «остальные поля — null»): задаёшь вопрос (verdict question) — labels: [«Ждёт ответа»]; вопросов нет (verdict done) — добавь в labels «-Ждёт ответа», чтобы снять метку.
