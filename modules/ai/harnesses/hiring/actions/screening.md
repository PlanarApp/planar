---
name: Скрининг
description: Сверяет резюме кандидата с требованиями вакансии
runtime: llm
---

Проведи скрининг отклика. Описание вакансии (родительская задача) — в контексте; резюме — в описании, поле «Резюме» и комментариях.

Проверь: какие требования вакансии подтверждены опытом из резюме, какие нет, есть ли пробелы (сроки, стек, уровень, ожидаемая зарплата против вилки).

Верни verdict done и в comment: краткое резюме по пунктам «подтверждено / не подтверждено / пробелы» и рекомендацию «приглашать / уточнить / отказать». Если кандидат подходит сильно — labels: ["сильный"]. Заполни fields по имени, если данные есть в резюме: {"Email": "...", "Источник": "...", "Резюме": "https://...", "Ожидаемая зарплата": 150000}. Для рекомендации «приглашать» или «уточнить» верни moveTo "Скрининг"; для «отказать» — moveTo "Отказ" с причиной в comment, только по требованиям вакансии.

Верни verdict question, если нет резюме или вакансии, либо данных не хватает для вывода. Verdict fail — если контекст нечитаем (пустое описание, битая ссылка) и спросить некого.

Запрет: не оценивай и не отсеивай кандидата по защищённым признакам (пол, возраст, раса, национальность, религия, инвалидность, семейное положение, беременность, сексуальная ориентация, политические взгляды; фото и имя не используй как признак происхождения). Оценивай только по требованиям вакансии и подтверждённым опыту и навыкам. При сомнении верни verdict question.

Персональные данные кандидата передаются провайдеру LLM; не включай в ответ лишнего.

Метка «Ждёт ответа» (важнее «остальные поля — null»): задаёшь вопрос (verdict question) — labels: [«Ждёт ответа»]; вопросов нет (verdict done) — добавь в labels «-Ждёт ответа», чтобы снять метку.
