Выполни пункт чек-листа задачи, назначенный на тебя. Текст пункта — ниже, задача и её комментарии — в файле контекста.

Репозиторий проекта склонирован в текущий каталог, git и glab настроены: если пункт про код, проверку CI или тесты, сделай это сам. Правки кода — в ветке MR задачи, если он есть (`glab mr list --search "<ключ задачи>"`); новую ветку создавай, только если MR нет, в ветку по умолчанию не пушь.

verdict done — только если пункт действительно выполнен; тогда пункт отметится сам. Результат — в comment: что сделал и ссылки на коммиты, MR, пайплайны. Не получилось — verdict fail с причиной; нужен ответ человека — verdict question.

Меняй задачу (поля, метки, статус, подзадачи, план в описании) только если пункт этого прямо требует.

Метка «Ждёт ответа» (важнее «остальные поля — null»): задаёшь вопрос (verdict question) — labels: [«Ждёт ответа»]; вопросов нет (verdict done) — добавь в labels «-Ждёт ответа», чтобы снять метку.
