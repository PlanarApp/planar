# Перевод публичных документов на английский

Решение пользователя (2026-10-30): документы публичного репозитория — на английском. Публикуется всё из `docs/contracts/` и `docs/guides/` (остальное `docs/` исключено из экспорта, `ops/export-exclude.txt`).

## Правила перевода

- Меняется только проза. Не менять: блоки кода и примеры JSON, имена полей и сущностей, идентификаторы контрактов (C-…), версии, ссылки, пути, команды, значения для UI в кавычках (русские строки интерфейса остаются, если это данные примера).
- Заголовки и фразы, которые читают контрактные тесты, не менять без проверки: перед отчётом прогнать контрактные тесты (список в карточке).
- Фронтматтер: `summary` перевести, остальные ключи не трогать. Размер документа ≤ 40 КБ.
- Термины: «мутатор» — mutator, «пространство» — space, «исполнитель» — executor, «шлюз» — gateway, «ярус» — tier. Не выдумывать, не сокращать смысл.

## Задачи

1. DEN-1: work.md, p4.md, pwa.md.
2. DEN-2: core.md, core-schema.md, core-api-v1.md, core-mutators.md, work-api.md.
3. DEN-3: design.md, collab.md, web.md.
4. DEN-4: p3.md, features.md, ops.md, launch.md, docs/guides/deploy.md, docs/guides/mcp.md (guides можно сверять с docs-site/en).

Приёмка у всех: остаток кириллицы вне блоков кода и кавычек минимален (число в карточке), контрактные тесты зелёные, `docs check` без ошибок.
