# Модуль ai7 (PLNRAPP-172)

## 1. Цель
`emails[]` из результата прогона ИИ не уходят сразу: бот выводит один комментарий-список на всю пачку, назначенный на человека. Reply «ок» отправляет пачку через `modules/email` батчем с задержкой; reply с правками перезапускает прогон. Итог отправки — в тот же тред. Источник: `build/ai-plan.md` §4 п.8, «Решения» (стр. 44).

## 2. Решения
- 2026-11-12 (coordinator, пользователь спит): одна задача AI7-1 (API + тесты + демо-сид), web не нужен — всё в треде комментариев.
- Миграция 0054 (0053 занята MR !162 PLNRAPP-171); правки `run.ts`/`index.ts` минимальные и локальные.
- «ок» — reply исполнителя комментария-пачки (не бот), текст после trim/lowercase из набора «ок», «ok», «да», «отправить», «отправляй»; любой другой текст — правки.
- Лимит в час на проект: константа в модуле (20 писем/час), превышающие письма переносятся `startAfter` на следующий час.

## 3. Задачи

### AI7-1. Письма пачкой (волна 1)
- Схема: таблица `ai_email_batches` (id, runId, taskId, projectId, commentId — комментарий-пачка, `state`: pending | sending | sent | cancelled, `emails` jsonb [{to, subject, body, state: queued|sent|failed, error?}], createdAt, updatedAt); миграция 0054.
- `resultSchema`: `emails` (nullable, ≤10: to, subject, body). Инструкция в SYSTEM; письма применяются при `done`.
- `apply`: при непустых `emails` — создаётся пачка и один комментарий-список (кому, тема, текст), назначенный на человека (как вопросы); прогон уходит в `waiting_human`; `questionCommentIds` не используется — подтверждение ищется по `ai_email_batches.commentId`.
- Подтверждение: в `afterMutation` reply в тред комментария-пачки от её исполнителя (не бот), пачка `pending`: «ок» → пачка `sending`, на каждое письмо job `ai.email` со сдвигом `startAfter` 30–60 с накопительно и лимитом в час на проект; правки → пачка `cancelled`, прогон перезапускается (resume/новый прогон с текстом правок в контексте). Идемпотентно (смена состояния одним `update … where state='pending'`).
- Отправка: job `ai.email` шлёт через `modules/email` (SMTP-конфиг, `send`); итог (отправлено N, ошибки) — комментарием в тот же тред от бота, когда все письма пачки обработаны.
- Тесты (vitest, рядом с тестами модуля ai): пачка создаётся и не отправляется без «ок»; «ок» от не исполнителя/бота игнорируется; «ок» ставит джобы с задержкой, лимит в час; правки отменяют пачку и перезапускают; итог в тред; повторное «ок» ничего не меняет.
- Демо-сид `apps/api/src/db/seed-demo.ts` (только сидом; формат проверяет `apps/api/test/seed-demo.test.ts`).
- Проверки: `pnpm --filter @planar/api test <фильтр>`, полный `pnpm test`, `pnpm -s lint`.
