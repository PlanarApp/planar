# Модуль tails (UT)

## 1. Цель
Добить визуальные хвосты после слияния фазы 3 в `main` (8ba1d52), по C-ui v4. Без новых функций.

## 2. Решения пользователя (2026-10-25)
- Тёмная боковая панель остаётся в обеих темах.
- Довести визуальные хвосты.
- Тёплый старт 459 мс принят без доводки.

## 3. Задачи
- **UT-1.**
  1. Карточка доски компактная: высота по содержимому, без пустого места; ID и приоритет в одну строку с названием; нижняя строка (метки, срок, аватары) только если есть что показать.
  2. На телефоне хлебные крошки показывают проект и вид («Planar › Список»), пространство можно опустить.
  3. Раздел «Чат» в боковой панели: подзаголовки и пункты («Нет каналов», «Личные», каналы) выровнены по сетке остальных секций (отступ, высота 28 px, размер шрифта).
  4. Экран входа: логотип и название, карточка формы по центру, акцентная кнопка, тёмная тема; не заглушка.
  5. Иконка приоритета «низкий» (SignalLow) читаемого размера, как у остальных приоритетов.
  6. Пустые ячейки строки списка (gridcell) занимают свою колонку, чтобы метки и аватары не прыгали.
  - Эталоны `e2e/web/visual.spec.ts` обновить только для затронутых экранов, с пояснением.

## 4. Правила
- Как в `docs/plan/design.md` §7: свои порты (не 3000/3300/5173), отчёт — `build/dpcli/<ID>.report.json` в своей копии, скриншоты «до/после» — в `build/artifacts/UT-1/`.
- Не больше 2 попыток на каждую мелочь.
- Бюджеты §7 не ухудшать, начальный JS ≤ 200 КБ.
