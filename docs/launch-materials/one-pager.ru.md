# Planar: коротко

**Быстрый и простой трекер задач для команд. Свой сервер, local-first, открытый код (Apache 2.0).** Версия 0.9.0, публичная бета.

## Что это
Трекер задач с локальной копией данных в браузере: интерфейс мгновенный и работает без сети. Один экземпляр — одно рабочее пространство.

## Что есть
- Задачи, подзадачи, чек-листы, метки, исполнители, комментарии, вложения, уведомления, Web Push.
- Устанавливаемое PWA, раскладки для десктопа и мобильных.
- REST API (`/api/v1`) и встроенный MCP-сервер (`/mcp`) с личными токенами (`read` или `write`) для ИИ-агентов.
- Модули в `modules/*`: sprints, time, forms, automations, webhooks, dashboards, docs, gitlab и другие; плагины-страницы в песочнице.
- Роли: owner, admin, member, guest.

## Свой сервер
`docker compose` с PostgreSQL 18, API и Caddy (автоматический TLS). Скрипты бэкапа, восстановления и обновления в `ops/`. Руководство: `docs/guides/deploy.md`.

## Услуги (планируются)
Проект планирует облачную версию, платное внедрение и разработку модулей на заказ. Пока ничего из этого не доступно, условия не опубликованы.
