# Planar documentation

Planar is a fast, simple task tracker for teams, with a local replica of your data in the browser, so the interface responds instantly and keeps working offline. One instance is one workspace. Self-hosted with Docker Compose, Apache-2.0 licensed.

- [Installation](/install): VPS, domain, first start
- [Configuration (.env)](/configuration): environment variables
- [Backups and upgrades](/backup-upgrade): `ops/backup.sh`, `restore.sh`, `upgrade.sh`
- [Monitoring and troubleshooting](/monitoring)
- [MCP](/mcp): connect AI agents
- [REST API](/rest): `/api/v1`, OpenAPI
- [Developing modules](/modules)

Repository: https://gitlab.com/planarhq/planar (mirror: https://github.com/PlanarApp/planar).
