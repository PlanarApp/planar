# Документация Planar

Planar — быстрый и простой трекер задач для команд с локальной репликой данных в браузере: интерфейс отвечает мгновенно и работает офлайн. Один инстанс — одно рабочее пространство. Self-hosted через Docker Compose, лицензия Apache-2.0.

- [Установка](/ru/install) — VPS, домен, первый запуск
- [Настройка (.env)](/ru/configuration) — переменные окружения
- [Бэкапы и обновление](/ru/backup-upgrade) — `ops/backup.sh`, `restore.sh`, `upgrade.sh`
- [Мониторинг и неполадки](/ru/monitoring)
- [MCP](/ru/mcp) — подключение ИИ-агентов
- [REST API](/ru/rest) — `/api/v1`, OpenAPI
- [Разработка модулей](/ru/modules)

Репозиторий: https://gitlab.com/planarhq/planar (зеркало: https://github.com/PlanarApp/planar). Домены planarhq.com, docs.planarhq.com, demo.planarhq.com — планируемые, ещё не зарегистрированы. Адреса hello@ и security@ тоже планируемые; о проблемах безопасности см. `SECURITY.md` в репозитории.
